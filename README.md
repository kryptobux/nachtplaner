# Nachtplaner – Werkzeuge

Private Werkzeuge zur Nachtplanung für die Astrofotografie.

- `horizont/` – Horizont-Aufnahme mit Handykamera, Kompass und Neigungssensor. Ergebnis sind 72 Zeilen „Azimut Höhe“, die der Nachtplaner unter Setup → Horizont einliest.

Die Seite speichert nichts auf einem Server. Standort und letzte Aufnahme bleiben im Browser des Handys.

Astronomy Engine 2.1.19 (MIT-Lizenz, Don Cross) liegt als `horizont/astronomy.browser.min.js` bei.
